About the Project

The Melissodes Project is an online resource dedicated to information about the genus of bee Melissodes. This project focuses on research, taxonomy, phylogeny, morphological traits, and natural history of these bees. Here you'll be able to find scientific articles about each species and the genus, detailed figures and diagrams, and taxonomic information.

Project Scope

This project's goal is to collect information about the genus Melissodes, including its taxonomy, morphology, and ecology. The Melissodes project serves as a resource for entomologists, ecologists, and citizen scientists by providing species and genus data, anatomical diagrams, figures, and references.

How to Use This Resource

1. Use the "article database search" to find species-level treatments documenting Melissodes sp. taxonomy, bionomics, identification, detailed descriptions, distribution, and phenology. The article database search is also a reverse synonym identifier, meaning if a synonymous name is input, the valid name will appear in the results.

2. Use the "species index" to quickly filter through subgenera and find the most up-to-date taxonomic list of Melissodes. Each species card is a button and leads to an article about that species, or, if an article isn't present, the species card leads to pictures.

3. Use the "gallery" to find figure, lab, and field images. Each gallery has its own search bar allowing for easy species lookup.
